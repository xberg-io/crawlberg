- Almost everything in `e2e/` is generated; do not edit it. Generator-owned files carry an `alef:hash:` provenance line in their header; that marker, not the directory, identifies them.
- Three files under `e2e/` are hand-written and are never regenerated over or deleted: `e2e/node/tests/ssrf.test.ts`, `e2e/wasm/tests/ssrf.test.ts`, `e2e/rust/tests/ssrf_test.rs` (SSRF-defence coverage, self-labelled in the first line). They carry no marker, so this list is the record.
- Their self-label never contains the substring `generated by alef`: alef's ownership predicate (`core::hash::content_has_alef_marker`) is a case-insensitive substring match over the first 10 lines with no negation handling, so "NOT generated by alef" made alef claim all three and report them stale and orphaned under `alef verify`.
- `e2e/go/helpers_test.go`, `e2e/go/main_test.go` and `e2e/elixir/test/test_helper.exs` are alef-owned (`alef verify` reports them FROZEN). Change them via fixtures or generator config. The old hand-added `Crawlberg.Native.set_env/2` call in the Elixir helper was dead: the function is not declared in `packages/elixir/lib/crawlberg/native.ex`.
- To change generated output: edit fixtures or generator source, run `task e2e:generate`, run `task e2e:test`, commit together.
- CI drift gate: the `e2e-tests` matrix in `.github/workflows/ci-e2e.yaml` runs `alef e2e generate --lang <lang>` and checks `git status --porcelain -uall` on that language's `e2e/` directory. Four of the 16 legs are excluded — `python`, `php`, `ruby`, `c` — so `ruby` and `c` output is not guarded against fixture drift.
  - Formatter missing on the runner (`python`, `php`): alef calls a bare `ruff` binary (not a project dependency) and `packages/php/vendor/bin/php-cs-fixer` (never installed in this job), so output would be unformatted.
  - Formatter present but not equivalent (`ruby`, `c`; observed on `9aaaf3410`): without bundler, alef downgrades `bundle exec rubocop` to a WARN and skips formatting; `clang-format` output is version-dependent.
  - `dart` has the same skew and is handled by pinning the SDK version in the matrix so `dart format` is a fixed point of the committed tree; prefer this for a new language.
  - The real fix is pinning every formatter toolchain; the silent WARN-and-skip is an alef defect. See the `~keep` comment above the check in the workflow.
- Generated-code gates here fail open; a green one is not evidence of correct output. `alef verify` hashes generation inputs, not output bytes ("present but NOT content-verified" files pass). Snapshot, `fmt --check` and `tsc` checks also pass on broken generated output.
- To prove a regeneration is clean: `alef cache clear` first ("Generated 0 files" is a cache report), generate twice, and require a byte-identical `git diff | shasum`.
